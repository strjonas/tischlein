# Breakfast cell

A fixed arm on a lift beside a fridge and a microwave, designed and tested in simulation.

- [build11](build11/README.md) is the design: model, planner, physics tests, parts list, print-fit files and an interactive 3D viewer.
- `build10` holds the base model (`model3d.py`) and the kinematic morning (`sequence.py`) that build11 extends and imports.
